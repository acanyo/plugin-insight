# 后续开发顺序

每阶段完成实现、对应测试和使用说明后交付，保持 Halo Console 的现有视觉风格。

1. 稳定性和权限：SQLite 读取竞争与生命周期保护、版本升级与并发回归、真实角色权限验证。
2. 插件诊断详情：从排行进入单插件视图，关联 CPU、分配量、慢请求、异常、启停及优化记录。
3. 告警现场快照：触发时持久化有限大小的指标和排行证据，恢复后仍可回看，敏感堆栈保持独立权限。
4. 业务任务接入：定义显式任务上报契约，接收其他插件的耗时、失败和积压；展示接入覆盖范围。
5. 站外探针状态：接入最近检查时间、宕机历史和通知结果，识别探针失联。
6. 通知人工重试：失败原因分类、终止后手动重试、重复抑制和操作记录。
7. 性能基线：昨天/上周与升级前后对比，标记采样覆盖和流量差异。

第一阶段发布记录见 [1.1.1 稳定性验证](verification-1.1.1.md)。后续阶段尚未实现，
不会将规划中的功能显示为已经可用。
