# 开发进度与后续顺序

每阶段完成实现、对应测试和使用说明后交付，保持 Halo Console 的现有视觉风格。

已完成：

- 1.1.1：SQLite 稳定性与权限修正，见 [验证记录](verification-1.1.1.md)。
- 1.1.7–1.1.8：减少持续监控工作，支持指定插件日志查询。
- 1.2.0：自身开销面板、压力评分拆解、插件诊断详情、告警现场、日志快照与性能基线。
  新接口的真实 Halo 角色验证仍需本地服务运行后复测；自动回归与交付范围见 [验证记录](verification-1.2.0.md)。

后续顺序：

1. 业务任务接入：定义显式任务上报契约，接收其他插件的耗时、失败和积压；展示接入覆盖范围。
2. 站外探针状态：接入最近检查时间、宕机历史和通知结果，识别探针失联。
3. 通知人工重试：失败原因分类、终止后手动重试、重复抑制和操作记录。

规划中的功能不会显示为已经可用。
